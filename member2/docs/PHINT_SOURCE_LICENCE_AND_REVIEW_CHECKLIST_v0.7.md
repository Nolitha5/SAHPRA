# Monograph approval worksheet (complete one per source and per applicable submission)

- [ ] Official publishing body and source URL independently checked (WHO/Ph.Int., or authorised BP/Ph.Eur./USP/IP distributor where permitted)
- [ ] Source filename, PDF page count, cryptographic SHA-256, date accessed and original file retained
- [ ] Edition/printing and amendment/supplement identified **from source itself**, including discrepancies between online title and PDF footer
- [ ] Legal terms and specific permission for local extraction, embedding, indexing, storage, and team redistribution established; record restrictions
- [ ] Substance name, salts/hydrates, stereochemistry, CAS and medicinal form match the sponsor dossier
- [ ] API versus dosage-form scope verified; S.4 Drug Substance does not automatically import S.P Drug Product standards
- [ ] Regulatory applicability for SAHPRA/filing pathway assessed by authorised domain reviewer
- [ ] Relevant submission date and source effective-from/effective-to reviewed
- [ ] Applicable general notices, tests, reagents, reference substances and chapter cross-references identified
- [ ] Extraction accuracy of figures/tables/chemical structures verified against PDF image by M3/domain reviewers
- [ ] Verified source chunks and page anchors can be traced back to original immutable PDF
- [ ] Evidence sufficiency rules, conflict handling and human-review pathway accepted by M5
- [ ] M4 independent gold-evidence labels available; provenance/false-negative tests passed

**Record:** reviewer, organisation/role, date, approved hash, rights evidence, effective edition and applicability explanation, outstanding flags. A CLI text attestation is not evidence of credentials or permission by itself.
