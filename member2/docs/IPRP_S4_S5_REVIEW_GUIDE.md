# IPRP QWGG S.4/S.5 supporting assessor guide (v1.1, 20 September 2018)

This document is nonbinding **model guidance**, covering *chemical drug substances* (not biological products). The source explicitly states that adoption by each authority is not mandatory. It is helpful as a **quality assessment reporting checklist**, not a new local regulation. The uploaded source PDF is archived in `regulatory_sources/additional_user_supplied` and indexed into page-level JSONL under `artifacts/iprp`.

These items are reproduced as *paraphrased review questions*, not as numeric requirements or automatic regulatory rejection criteria. The full IPRP source references older revisions (e.g. Q2(R1) and Q3C(R5)); source applicability must be reconciled with the available newer versions (Q2(R2), Q3C(R9)) by a qualified reviewer. The IPRP guide is not applicable automatically to all biologics cases.
