Member 2 — Official regulatory source collection

As checked 19 October 2026.

Important: All 15 distinct user-supplied regulatory PDFs are included with this ZIP. These links remain useful for checking for newer publisher editions. Files obtained via links still need source, edition, licensing and applicability review before regulatory use. ChromaDB/BGE real indexing and expert evaluation are separate steps.

How to refresh the collection from publishers

  1. Click Open official source in a source you need to update.
  2. Download the official PDF and save it with the exact filename shown in the table.
  3. After independently confirming a new edition, follow the update/reindex protocol rather than overwriting a validated file silently.
  4. Run python scripts/collect_validate_index.py --index --include-conditional from the project root. The script checks the file's PDF signature, text and matching document code before adding it to the technical preview.
  5. To build an actual semantic index on an appropriate workstation, install the optional dependencies and run the actual ChromaDB/BGE builder in the runbook.
